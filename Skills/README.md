# DCAD Skills — D1 đến D18

**Nguồn quy ước gốc:** https://github.com/Tidi6969/QuyUoc

Các Skill ở đây gồm `D1` … `D18`, mỗi thư mục có `SKILL.md` và `references/STANDARD.md` là snapshot toàn văn tại lúc lưu. D17 và D18 cũng đã có SKILL.md riêng.

## Quy tắc kích hoạt
- **Mọi lần viết, sửa, build code DCAD: bắt buộc dùng D17 và D18.**
- Tùy chức năng đang làm, áp dụng thêm D1–D16 và toàn bộ quy ước liên quan/được viện dẫn.
- **Trước khi làm phải đọc toàn văn phiên bản mới nhất từ thư mục gốc GitHub**. Không coi Skill hoặc snapshot là bản thay thế quy ước.
- Tự đối chiếu từng cổng/tiêu chí; chỉ nhận PASS khi có chứng cứ; không đạt cổng bắt buộc → HARD STOP.
- Ghi trạng thái riêng build, NETLOAD, Runtime, GitHub theo từng CAD host, không suy đoán.

## Cài đặt và phát hành
- GitHub giữ **bản mã nguồn Skill**, không phải danh sách Skill đã cài trong tài khoản ChatGPT.
- Người dùng cần import/cài qua giao diện hỗ trợ Skills của tài khoản; GitHub connector không thể tự cài Skill.
- Mỗi khi sửa nội dung quy ước gốc, Skill đang chạy phải đọc live bản mới nhất. Bản snapshot này chỉ là bản lưu tại thời điểm tạo.
